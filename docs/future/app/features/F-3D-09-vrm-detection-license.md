## 0. 完成系での位置づけ（逆算リンク）

由来する完成系:

- **T-DONE-3**: ファイルサイズ・ポリゴン数・…・**VRM を検品できる**。
- **T-DONE-1**: 安全に読み込める（**拡張データを壊さず保つ**）。

逆算の理由: 人型アバター形式は、**形式そのものが利用条件を内包している**点で他と違う。多くの 3D モデルは「使ってよいか」がファイルの外にあるが、この形式は**中に書いてある**。

これは本コンセプトにとって好都合である。`F-3D-13` は「利用条件を記録する」と定めたが、**記録すべき内容がファイル自体に含まれている**なら、取りこぼしが減る。ただし——**中に書いてあることを、機械が正しいと保証はできない**。その線引きが本機能の要になる。

## 1. ユーザーストーリー

- 制作者として、**このモデルが人型アバター形式かどうか**を知りたい。
- 制作者として、**中に書かれている利用条件**（商用の可否・改変の可否・再配布の可否など）を読みたい。
- 制作者として、**自分の申告と食い違っていたら教えてほしい**。
- 制作者として、**この形式を扱っても、元のファイルが壊れない**と確信したい。
- 制作者として、**扱えない部分があるなら、先に知りたい**。

## 2. 用語

- **拡張データ**: 基本形式に上乗せされた、形式固有の情報。
- **内包された利用条件**: ファイル内部に記録された、使ってよい範囲。
- **素通し**: 中身を解釈せず、バイト列のまま保持して出すこと。

## 3. 機能要件（FR）

### 3.1 素通しが成り立つこと（継承の土台）

- **FR-1** この形式は **基本形式として読み込め、書き出せる**。拡張データは **未知のものとして保持**する（系譜: 上流 §5.1 の V0。**追加の実装なしで成立する**のが理想）。
- **FR-2** **拡張データをバイト列のまま保持**する（`F-3D-01` FR-10 / `F-3D-02` FR-20「未知の塊を捨てない」がそのまま効く。`D3`）。
- **FR-3** **解釈できない部分があっても、取り込みを拒否しない**（FR-1 が成り立つ限り。`F-3D-02` FR-18 の「拒否は資源枯渇に直結するものに限る」と同じ）。

### 3.2 検出と表示

- **FR-4** **この形式であることと、その版を検出して表示**する（系譜: 上流 §5.1 の V1）。
- **FR-5** **内包された利用条件を読み取って表示**する（作者・題名・**商用の可否・改変の可否・再配布の可否・利用範囲の条件**など。系譜: 同上。**推奨最低ライン**とされている）。
- **FR-6** **人型の骨の一覧**を表示する（`F-3D-08` の対応付けと接続）。
- **FR-7** **扱えない要素（揺れもの・表情など）の有無を表示**する（系譜: 同上。**「あるが扱わない」を隠さない**）。

### 3.3 利用条件の扱い（継承の核心）

- **FR-8** 内包された利用条件は **`F-3D-13` へ参考として転記**する（系譜: 上流 §5.2）。
- **FR-9** **利用者が申告した利用条件を正とし、自動で上書きしない**（系譜: `3D-RISK-05` / `F-3D-13` FR-6・FR-7。**機械が権利を決めない**）。
- **FR-10** **申告と内包内容が食い違う場合、警告する**（例: 内包が商用不可なのに申告が商用可。系譜: 上流 §5.1 の V2）。**警告に留め、勝手に直さない**。
- **FR-11** **内包内容の正しさを検証・保証しない**（系譜: 上流 §5.2 の明示。ADR-0013 と同じ境界。**記録と表示までが本機能の責務**）。
- **FR-12** **内包内容が未記入なら、その旨を警告**する（系譜: 同上 V2。**空欄を「制限なし」と読ませない**。`F-3D-13` FR-8 と同じ）。
- **FR-13** 利用条件は **書き出しの説明にも載る**（`F-3D-15` FR-8/FR-9。**未確認なら「未確認」と明示**）。

### 3.4 検査

- **FR-14** **人型として必要な骨の欠落を検査**できる（系譜: 上流 §5.1 の V2。`F-3D-08` FR-15 と同じ検査を、この形式の要件として行う）。
- **FR-15** 検査は **`F-CORE-06` FR-7a〜7f の形**の指摘を出す（`F-3D-04` と同じ）。
- **FR-16** 検査は **read-only**（ADR-0014）。

### 3.5 書き出し（継承）

- **FR-17** この形式を書き出す場合、**素通し（バイト列不変）のみ**とする（系譜: 上流 §5.2）。
- **FR-18** **内包された利用条件を書き換えた派生を作らない**（系譜: 同上。**権利の記述を機械が編集しない**）。

### 3.6 表示の深さ（別判断）

- **FR-19** 拡張の内容（揺れもの・表情など）を**反映した表示は、別途の判断**とする（系譜: 上流 §5.1 の V3 が「第四段階の候補」であり、**通常の形式として表示できれば完成条件は満たす**としたのと同じ立場）。
- **FR-20** そのための外部部品を採る場合、**ライセンス検証ゲートを通る**（`G1` / `F-MOD-04`）。**候補名を採用として書かない**。
- **FR-21** 反映した表示を**モジュールとして足せる**（`A4`）。**未導入でも基本の表示と検品は成立する**（`P4` / `D3`）。

## 4. 非機能要件（NFR）

- **NFR-1（素通しの保証）**: 解釈できなくてもバイト列が保たれる（FR-2。`D3`）。
- **NFR-2（権利の慎重さ）**: 機械が利用条件を決めず、書き換えない（FR-9/FR-11/FR-18）。
- **NFR-3（正直さ）**: 扱えない要素・未記入・食い違いを隠さない（FR-7/FR-10/FR-12）。
- **NFR-4（非破壊）**: 元ファイルが不変（FR-2/FR-17。`G5`）。
- **NFR-5（read-only）**: 検査がデータを書き換えない（FR-16）。
- **NFR-6（ゼロコスト）**: 深い表示を導入しなくても成立する（FR-21。`P4`）。

## 5. データ・保存への影響

- **拡張データはバイト列のまま保持**（FR-2。`F-3D-01` FR-10 と同じ）。
- **転記した利用条件は「参考」として区別できる形**で持つ（FR-8。**申告と混ぜない**。`F-3D-13`）。
- **書き出しは素通しのみ**（FR-17）。保存データの意味を変えない。
- 検査結果は **`F-3D-14` の記録**に載る。

## 6. 依存機能

- **F-3D-01**（安全読み込み）: 素通しと原本保持の土台（FR-1/FR-2）。
- **F-3D-02**（多形式）: 「未知の塊を捨てない」規律（FR-2/FR-3）。
- **F-3D-13**（metadata）: 利用条件の転記先（FR-8〜FR-12）。
- **F-3D-08**（骨格）: 人型の骨の一覧と欠落検査（FR-6/FR-14）。
- **F-3D-04**（構造検査）: 検査の枠（FR-15）。
- **F-3D-14**（記録）: 検査結果の記録先。
- **F-3D-15**（書き出し）: 素通しと説明への反映（FR-13/FR-17）。
- **F-MOD-04**（ライセンス検証）: 深い表示の部品の門（FR-20）。

## 7. 受け入れ条件（Acceptance）

- **AC-1**: この形式が **基本形式として読み込め、書き出せる**（FR-1）。
- **AC-2**: **拡張データがバイト列のまま保持**される（FR-2/NFR-1/NFR-4）。
- **AC-3**: 解釈できない部分があっても**取り込みが拒否されない**（FR-3）。
- **AC-4**: **形式と版が検出・表示**される（FR-4）。
- **AC-5**: **内包された利用条件（商用・改変・再配布・利用範囲）が表示**される（FR-5）。
- **AC-6**: **人型の骨の一覧**が表示される（FR-6）。
- **AC-7**: **扱えない要素の有無が表示**される（FR-7/NFR-3）。
- **AC-8**: 内包内容が **`F-3D-13` へ「参考」として転記**され、申告と区別される（FR-8）。
- **AC-9**: **申告が正**であり、**自動上書きされない**（FR-9/NFR-2）。
- **AC-10**: **申告と内包内容の食い違いが警告**され、**勝手に直されない**（FR-10）。
- **AC-11**: **内包内容の正しさが検証・保証されない**（FR-11/NFR-2）。
- **AC-12**: **未記入が警告**され、空欄が「制限なし」と読まれない（FR-12/NFR-3）。
- **AC-13**: 利用条件が**書き出しの説明に載り、未確認なら「未確認」と明示**される（FR-13）。
- **AC-14**: **人型として必要な骨の欠落が検査**される（FR-14）。
- **AC-15**: 検査が **`F-CORE-06` FR-7a〜7f の形**の指摘を出し、**read-only** である（FR-15/FR-16/NFR-5）。
- **AC-16**: 書き出しが**素通しのみ**で、**利用条件を書き換えた派生が作られない**（FR-17/FR-18/NFR-2）。
- **AC-17**: **深い表示を導入しなくても、基本の表示と検品が成立**する（FR-21/NFR-6）。
- **AC-18**: 深い表示の部品が**ライセンス検証を通らずに入らない**（FR-20）。

## 8. 非目標

- **この形式の作成・変換**（他形式からの変換を含む。系譜: 上流 §5.1 の対象外。**専用ツールの仕事**）。
- **揺れもの・表情・視線の編集**（同上）。
- **内包された利用条件の書き換え**（FR-18）。
- **利用条件の正しさの判定・保証**（FR-11。**記録と表示まで**）。
- 拡張を反映した表示（FR-19。**別判断**）。
- 採用部品の選定（`G1` の評価が先。**候補名を採用として書かない**）。
