## 0. 完成系での位置づけ（逆算リンク）

由来する完成系:

- **T-DONE-6**: 元を壊さず軽量化した別モデルを作り、**前後を比較して選べる**。

逆算の理由: `T-DONE-6` は 3 つの動詞で構成される——**作る**（`F-3D-10` / `F-3D-11`）、**比較する**、**選ぶ**。本機能は後ろ 2 つを担い、**`T-DONE-6` を完成させる**。

そして本機能があることで、軽量化の設計全体が成立する。**「勝手に強く削らない」（`F-3D-10` FR-5）と「見た目が変わる処理はプレビューしてから適用」（同 FR-7）は、比較して選べる場所があって初めて実用になる**。比較が無ければ、制作者は「軽くしていいか」を判断できず、結局**軽量化を使わない**。

## 1. ユーザーストーリー

- 制作者として、**軽くした結果と元を、並べて見たい**。
- 制作者として、**どこが変わったか**を知りたい（全体を見ても気づけない）。
- 制作者として、**どれだけ軽くなったか**を数値で知りたい。
- 制作者として、**複数の候補から選びたい**。
- 制作者として、**比較しただけでは何も変わらない**と確信したい。
- 制作者として、**選ばない自由**が欲しい（元のままでよい場合もある）。

## 2. 用語

- **候補**: `F-3D-10` / `F-3D-11` が作った、軽量化済みの別モデル。
- **採用**: 候補を書き出し対象として選ぶこと。
- **差**: 元と候補の違い（見た目・数値）。

## 3. 機能要件（FR）

### 3.1 見て比べる

- **FR-1** 元と候補を **並べて / 切り替えて / 重ねて**比較できる（**どれか一つの見せ方に固定しない**——**破綻の見え方は場合による**）。
- **FR-2** **同じ視点・同じ条件で比較**できる（**視点が違えば比較にならない**）。
- **FR-3** **どこが変わったか**を示せる（差の目立つ箇所へ導く）。**全体を眺めて気づけ、としない**。
- **FR-4** 比較は **`F-3D-03` の面の上**で行う（別系統のビューアを作らない）。

### 3.2 数値で比べる

- **FR-5** **前後の数値差**を示す（ファイルサイズ・頂点数・三角形数・マテリアル数・テクスチャ枚数と最大サイズ。系譜: 上流 §6「最適化前後の差を表示する」）。
- **FR-6** 数値は **`F-3D-03` の検品項目と同じ指標・同じ言い方**で示す（**同じものを別の名前で呼ばない**）。
- **FR-7** **対象環境プリセットに対する評価の変化**を示す（`F-3D-03` FR-9。**「モバイルでは重すぎる」が「収まった」に変わったか**が、最も知りたい情報である）。

### 3.3 選ぶ（自動確定しない）

- **FR-8** **複数の候補から選べる**（`F-3D-10` FR-3 / `F-3D-11` FR-13 が作る候補群）。
- **FR-9** **採用は制作者が行う**。**自動で最良を選ばない**（`F-2D-15` FR-9 / `F-3D-10` FR-7 と同じ規律）。
- **FR-10** **採用しない**ことを選べる。**元のまま先へ進める**（系譜: 上流 §11「初期では optimized model を必須にしない」）。
- **FR-11** **採用は取り消せる**（`F-CORE-04`）。**採用後も元と他の候補は残る**（`F-3D-10` FR-1）。
- **FR-11a** **説明できない出力差を伴う軽量化を採用しない**（系譜: 上流 `EXTERNAL_GITHUB_REFERENCE_CATALOG.md` `IDEA-3D-09`。**「なぜか変わったが軽くなったので良し」を通さない**——原因の判らない差は、別の場面で別の壊れ方をする）。
- **FR-11b** **見た目の一致だけで、意味上の正しさを合格にしない**（系譜: 同上。基準・アンカー・判定が保たれているかは、絵では判らない。`F-3D-10` FR-13 の検証と対で見る）。

### 3.4 比較そのものは何も変えない

- **FR-12** 比較は **read-only** である。**比較しただけでプロジェクトが変わらない**（系譜: ADR-0014 / `F-2D-15` FR-4 / `F-3D-03` FR-13 と同じ）。
- **FR-13** 採用の操作**だけ**が状態を変え、**その操作は履歴に乗る**（`F-CORE-04`）。

### 3.5 実行

- **FR-14** 大きなモデルの同時表示・差の算出で **UI を固めない**（`PF3` / `F-PLT-03`）。
- **FR-15** 差の算出は **決定的**である（同じ組み合わせに同じ結果。`F-3D-10` FR-15 と同じ）。
- **FR-16** 比較できない場合（候補が無い・条件が揃わない）は、**理由を示す**（`F-CORE-06`）。

## 4. 非機能要件（NFR）

- **NFR-1（比較の公正さ）**: 同じ条件で比べられる（FR-2）。
- **NFR-2（気づける）**: 差のある場所へ導く（FR-3）。
- **NFR-3（一貫性）**: 数値の指標と言い方が検品と同じ（FR-6）。
- **NFR-4（自動確定しない）**: 選ぶのは制作者（FR-9）。
- **NFR-5（read-only）**: 比較で何も変わらない（FR-12）。
- **NFR-6（選ばない自由）**: 元のままでも進める（FR-10）。
- **NFR-7（応答性）**: 同時表示で UI を固めない（FR-14）。

## 5. データ・保存への影響

- **比較は保存データを変更しない**（FR-12）。
- **採用の結果（どの候補を書き出し対象とするか）は保存し得る**。additive / 名前空間分離（`D4`）。
- **元と非採用の候補は残る**（FR-11。`F-3D-10` FR-1）。
- 書き出しでの扱いは **`F-3D-15`** が担う。

## 6. 依存機能

- **F-3D-10 / F-3D-11**（軽量化）: 候補の作り手。
- **F-3D-03**（ビューポート & 検品）: 表示面と数値指標（FR-4/FR-6/FR-7）。
- **F-CORE-04**（履歴）: 採用の取り消し（FR-11/FR-13）。
- **F-CORE-06**（検品）: 比較できない理由の提示（FR-16）。
- **F-PLT-03**（offload）: 同時表示・差の算出（FR-14）。
- **F-3D-15**（書き出し）: 採用結果の利用先。

## 7. 受け入れ条件（Acceptance）

- **AC-1**: 元と候補を **並べて / 切り替えて / 重ねて**比較できる（FR-1）。
- **AC-2**: **同じ視点・同じ条件**で比較される（FR-2/NFR-1）。
- **AC-3**: **どこが変わったか**が示される（FR-3/NFR-2）。
- **AC-4**: **前後の数値差**が示される（FR-5）。
- **AC-5**: 数値が **`F-3D-03` と同じ指標・同じ言い方**（FR-6/NFR-3）。
- **AC-6**: **対象環境プリセットに対する評価の変化**が判る（FR-7）。
- **AC-7**: **複数候補から選べる**（FR-8）。
- **AC-8**: **自動で最良が選ばれない**（FR-9/NFR-4）。
- **AC-9**: **採用しないことを選べ、元のまま先へ進める**（FR-10/NFR-6）。
- **AC-10**: **採用を取り消せ**、**元と他の候補が残る**（FR-11）。
- **AC-11**: **比較しただけでプロジェクトが変わらない**（FR-12/NFR-5）。
- **AC-12**: 採用の操作が**履歴に乗る**（FR-13）。
- **AC-13**: 同時表示・差の算出で **UI が固まらない**（FR-14/NFR-7）。
- **AC-14**: 差の算出が**決定的**（FR-15）。
- **AC-15**: 比較できない場合に**理由が示される**（FR-16）。

## 8. 非目標

- 自動での最良候補の選択（FR-9）。
- 画質の自動評価による合否判定（**見て決めるのが本機能の趣旨**。指標を出すことは可だが、**合否を機械が決めない**）。
- 候補の生成（**F-3D-10** / **F-3D-11**）。
- 書き出しでの扱い（**F-3D-15**）。
- 比較 UI の具体（実装時に判断。**見せ方を一つに固定しない**という要件だけを固定）。
- 2D 側の前後比較（`F-2D-14` の preview が担当。**別機能**）。
