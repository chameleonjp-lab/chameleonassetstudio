## 0. 完成系での位置づけ（逆算リンク）

由来する完成系:

- **T-DONE-8**: model + metadata + report + README + import notes の ZIP を、**対象別 preset つきで書き出せる**。
- **T-DONE-9**: 元の 3D モデルを絶対に上書きしない。

逆算の理由: **3D パイプラインの出口**。`F-3D-01`（取り込み）から `F-3D-14`（記録）までの成果が、外部で実を結ぶかどうかが決まる場所であり、**`F-2D-16`（2D の出口）と対**をなす。

そして 2D と同じ原則がここでも中心になる——**「対応」という言葉を曖昧にしない**。加えて 3D 固有の重心が一つある: **既定では、モデルに手を加えずに出す**。

## 1. ユーザーストーリー

- 制作者として、**対象を選ぶだけ**で必要な一式が出てほしい。
- 制作者として、**元のモデルがそのまま入っている**と安心できる。
- 制作者として、**取り込み手順**と**座標系の説明**が付いてきてほしい。
- 制作者として、**同じ設定なら同じものが出る**と確信したい。
- 制作者として、**その対象で本当に動くのか**を知りたい。
- 制作者として、**失敗したら中途半端な ZIP を作らないで**ほしい。

## 2. 用語

- **成果物一式**: モデル・付随データ・検査記録・説明・取り込み手順をまとめたもの。
- **焼き込み**: 整備した変換をモデル自体へ適用すること。
- **対応区分**: その対象でどこまで確かめられているかの表示。

## 3. 機能要件（FR）

### 3.1 既定では手を加えない（継承 — 3D の重心）

- **FR-1** **既定では、モデルを取り込んだままの姿で出す**（系譜: 上流 §8.2「モデルは常に source のまま出す」。**出力で勝手に作り変えない**）。
- **FR-2** 整備した基準（`F-3D-05`）は **付随データとして同梱**し、**変換は受け取り側の作業として取り込み手順に書く**（系譜: 同上）。
- **FR-3** **焼き込む選択肢を設ける場合も、既定は無効**とする（系譜: 同上）。特に **骨・動きを持つモデルでは既定を無効にし、警告する**（**変換の焼き込みは、骨や動きと組み合わさると壊れやすい**）。
- **FR-4** 焼き込みは **`F-3D-05` FR-20 の「一度だけ適用」に従う**（系譜: `3D-RISK-01` の二重適用防止。**表示で 1 回・書き出しで 1 回掛かって 2 回回る**を防ぐ）。

### 3.2 何を同梱するか

- **FR-5** **モデル本体・付随データ（`F-3D-13`）・検査記録（`F-3D-14`）・説明・取り込み手順**を同梱できる。
- **FR-6** **一式の目録**を持つ（含まれるファイル・大きさ・内容を特定する値・役割。系譜: 上流 §8.3 の manifest）。
- **FR-7** 目録は **元モデルの特定値と元のファイル名**を持つ（**どのモデルから作られた一式か**が判る。`F-3D-14` FR-4 と同じ規律）。
- **FR-8** 説明には、少なくとも **座標系の約束・整備した基準の値・アンカーと判定の一覧・利用条件・既知の制限**を含める（系譜: 上流 §8.4）。
- **FR-9** **利用条件が未確認なら「未確認」と明示**する（`F-3D-13` FR-8。**空欄で渡さない**）。

### 3.3 再現できる出力（継承）

- **FR-10** **同じ入力・同じ設定・同じアプリ版から、同じ内容の一式を再現できる**（系譜: 上流 §8.5。`F-2D-16` FR-14 と同じ規律）。
- **FR-11** 再現のため、**まとめ方の揺れを固定**する（含まれるファイルの並び順、時刻情報、整形の仕方）。
- **FR-12** **時刻のような「毎回変わる値」は、目録の 1 か所にだけ置き、他のファイルへ埋め込まない**（系譜: 同上。**あちこちに時刻が入ると、それだけで毎回別物になる**）。
- **FR-13** **再現できない操作を含む場合は、その旨と理由を明示**する（系譜: 同上。**黙って「再現できます」と言わない**）。
- **FR-14** **再現性を自分で確かめられる**（同じ入力から 2 回作って一致を見る。系譜: 同上）。

### 3.4 「対応」を曖昧にしない（継承）

- **FR-15** 対象ごとに **対応区分を表示**する。少なくとも **確認済み / 対応作業中 / 手順書のみ / 対象外**を区別する（系譜: 上流 §8.6・`2D_EXPORT_COMPATIBILITY_MATRIX.md`）。
- **FR-16** **説明を書いただけの対象を「確認済み」と表示しない**（系譜: 同上の明示。`F-2D-16` FR-2 と同じ）。確認済みには **記録**（対象・版・確認日・環境・素材種別・期待結果・既知の制限）を要する。
- **FR-17** **対応区分は対象とその版に紐づく**（`F-2D-16` FR-3 と同じ）。
- **FR-18** **対象外は理由と代替手順を示して明示的に断る**（`F-2D-16` FR-6 と同じ）。
- **FR-19** **専用形式の完全な読み書き・ランタイム互換を名乗らない**（`F-2D-16` FR-5 と同じ）。

### 3.5 対象ごとの制約を一か所から見る（継承）

- **FR-20** 対象ごとの制約（骨の数・頂点あたりの影響数・命名の規則など）は、**書き出し前の検査・取り込み手順・検品プリセットの三か所が同じ所在を参照**する（系譜: 上流 `3D-RISK-11`。**別々に値を書くと必ずずれ、書き出しは成功するのに対象側で壊れる**）。`F-3D-03` FR-11a と同じ規律。
- **FR-21** 制約に触れる場合、**書き出し前に理由つきで警告または拒否**する（`F-CORE-06` の出力検証）。

### 3.6 安全な一式（継承）

- **FR-22** 一式の中の位置は **相対の位置のみ**とし、**上位を辿る表記・先頭の区切り・制御文字を含めない**（系譜: 上流 §8.7。`F-3D-01` FR-5 / `F-MOD-02` FR-7b と同じ思想。**受け取り側で展開したときに、意図しない場所へ置かれない**）。
- **FR-23** 名前は **安全な形へ整える**。**同名の衝突は決定的な規則で解決**する（系譜: 同上。FR-10 の再現性と整合）。

### 3.7 失敗の扱い（継承）

- **FR-24** **書き出し前に妥当性を確かめ、不正なら一式を作らない**（系譜: 上流 §9。`F-CORE-07` の原子性 / `F-2D-16` FR-21 と同じ）。
- **FR-25** **元モデルが見つからない場合は中止し、復旧の手段を案内**する（系譜: 同上。**「書き出せません」だけにしない**）。
- **FR-26** 進行を表示し、**取消できる**。取消で**中途半端な成果物を残さない**（系譜: 同上）。
- **FR-27** **loss がある出力は、理由つきで拒否するか、確定前に開示して確認を求める**（`F-CORE-07` / `F-2D-16` FR-19 と同じ）。

### 3.8 器と拡張

- **FR-28** 書き出しは **`F-CORE-07` の書き出しフレーム**に載る（独自経路を作らない）。
- **FR-29** **モジュールが対象別 preset を追加できる**（`A4`）。ただし **同じ対応区分の規律・同じ記録要件に従う**（`F-2D-16` FR-22 と同じ。**モジュール由来だからといって「確認済み」を名乗れない**）。

## 4. 非機能要件（NFR）

- **NFR-1（非破壊）**: 既定でモデルに手を加えない（FR-1。`G5`）。
- **NFR-2（再現性）**: 同じ入力が同じ結果になる（FR-10〜FR-14）。
- **NFR-3（正直さ）**: 確かめていないものを確かめたと言わない（FR-15〜FR-19）。
- **NFR-4（単一の所在）**: 対象ごとの制約を二重に持たない（FR-20）。
- **NFR-5（安全）**: 展開先を汚さない一式（FR-22/FR-23）。
- **NFR-6（原子性）**: 失敗が中途半端な成果物を残さない（FR-24/FR-26）。
- **NFR-7（実用性）**: 手順まで含めて、人が実際に持ち込める（FR-8）。

## 5. データ・保存への影響

- **保存データを変更しない**。出力は成果物であり、`F-CORE-05` の保存内容に影響しない（FR-1）。
- **preset は設定データ**として保存し、編集データと分ける（`F-2D-16` と同じ。`adr/0007` の層分離）。
- **検査記録は `F-3D-14` から受け取る**（FR-5）。制作上の関係情報は出さない（`F-2D-14` FR-24 と同じ思想）。
- **対象ごとの制約の確定値は一つの所在**に置く（FR-20）。

## 6. 依存機能

- **F-CORE-07**（書き出しフレーム）: 器（FR-28）。
- **F-CORE-06**（検品）: 出力前検証と loss（FR-21/FR-24/FR-27）。
- **F-3D-13**（metadata）: 同梱する付随データ（FR-5/FR-9）。
- **F-3D-14**（report）: 同梱する検査記録（FR-5）。
- **F-3D-05**（基準）: 同梱する基準値と、対象ごとの変換の担い手（FR-2/FR-4）。
- **F-3D-06 / 07**（アンカー / 判定）: 説明に載せる一覧（FR-8）。
- **F-3D-10 / 11 / 12**（軽量化・比較）: 採用した候補の同梱（FR-13 の再現性の但し書きと連動）。
- **F-3D-03**（検品プリセット）: 制約の所在の共有（FR-20）。
- **F-MOD-01 / 02**（カタログ・導入）: 対象別 preset をモジュールとして足す（FR-29）。
- **F-PLT-03**（offload）: 大きな一式の生成（FR-26）。

## 7. 受け入れ条件（Acceptance）

- **AC-1**: **既定でモデルが取り込んだままの姿**で出る（FR-1/NFR-1）。
- **AC-2**: 整備した基準が**付随データとして同梱**され、**変換は取り込み手順に書かれる**（FR-2）。
- **AC-3**: 焼き込みの**既定が無効**であり、**骨・動きを持つモデルでは警告**される（FR-3）。
- **AC-4**: 焼き込みが**二重に適用されない**（FR-4）。
- **AC-5**: **目録**に含まれるファイル・大きさ・特定値・役割が載る（FR-6）。
- **AC-6**: 目録から**どのモデルから作られた一式か**が判る（FR-7）。
- **AC-7**: 説明に**座標系・基準値・アンカーと判定の一覧・利用条件・既知の制限**が載る（FR-8/NFR-7）。
- **AC-8**: **利用条件が未確認なら「未確認」と明示**される（FR-9）。
- **AC-9**: 同じ入力・同じ設定・同じアプリ版で**同じ内容の一式が再現**される（FR-10/NFR-2）。
- **AC-10**: **毎回変わる値が目録の 1 か所にだけ**置かれる（FR-12）。
- **AC-11**: **再現できない操作を含む場合、その旨と理由が明示**される（FR-13）。
- **AC-12**: **再現性を 2 回の書き出しで確かめられる**（FR-14）。
- **AC-13**: **説明を書いただけの対象が「確認済み」と表示されない**（FR-16/NFR-3、`F-2D-16` AC-2 と同じ規律）。
- **AC-14**: 対応区分が**対象の版に紐づく**（FR-17）。
- **AC-15**: 対象外が**理由と代替手順つきで断られる**（FR-18）。
- **AC-16**: 対象ごとの制約が**書き出し前検査・取り込み手順・検品プリセットで同じ所在**を参照する（FR-20/NFR-4）。
- **AC-17**: 制約に触れる場合に**理由つきで警告または拒否**される（FR-21）。
- **AC-18**: 一式の中の位置が**相対のみ**で、**上位を辿る表記や制御文字を含まない**（FR-22/NFR-5）。
- **AC-19**: **同名の衝突が決定的な規則で解決**される（FR-23）。
- **AC-20**: 不正なら**一式を作らない**（FR-24/NFR-6）。
- **AC-21**: **元モデルが見つからない場合、中止して復旧手段が案内**される（FR-25）。
- **AC-22**: 取消で**中途半端な成果物が残らない**（FR-26）。
- **AC-23**: **loss がある出力が黙って出ない**（FR-27）。
- **AC-24**: **モジュール提供の preset も同じ対応区分の規律・記録要件**に従う（FR-29）。

## 8. 非目標

- 対象ツール一覧・対応形式の確定（実装時／モジュールで判断。**区分の規律と記録要件だけ**を固定）。
- **焼き込みの既定有効化**（FR-3。ゲートであり禁止ではない）。
- 対象アプリのプロジェクト内部ファイルの生成（`F-2D-16` FR-10 と同じ）。
- 専用形式の完全な読み書き・ランタイム互換（FR-19）。
- 書き出しフレームそのものの定義（**F-CORE-07**）。
- 検査記録の形式（**F-3D-14**）、付随データの中身（**F-3D-13**）。
- 直接連携（plugin / addon）の実装（`F-2D-16` FR-8 と同じく**手順書を優先**。必要性が示されてから別判断）。
