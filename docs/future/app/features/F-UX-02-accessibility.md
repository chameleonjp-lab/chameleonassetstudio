## 0. 完成系での位置づけ（逆算リンク）

由来する完成系:

- **S-DONE-4**: 失敗・制限が分かり、**手動で必ず回復できる**。
- **S-DONE-3**: 2D と 3D が同じ操作感で行き来できる。

逆算の理由: 上流の情報設計が最初に置いた原則は、単なる補助機能の話ではなかった——**「Canvas だけに情報を依存させない。視覚的に確認できない利用者も、すべての作業（読み込み → 検品 → 設定 → 書き出し）を完了できる」**（系譜: 上流 §1-1）。

これは **「あとから読み上げ対応を足す」とは根本的に違う**。**描画面を、情報の唯一の出どころにしない**という**設計の制約**であり、機能が出揃った今、横断の要件として固定する意味がある。

そして本コンセプトにとって、これは**制作物の側にも効く**。`F-2D-13`（パレット）や `F-3D-07`（判定の目的）で **色だけに意味を持たせない**と決めたのと同じ規律が、道具そのものにも適用される。

## 1. ユーザーストーリー

- 制作者として、**描画面が見えなくても、作業を最後まで終えられる**ようにしたい。
- 制作者として、**キーボードだけで一通り操作できる**と助かる。
- 制作者として、**色が区別しづらくても、状態が分かる**ようにしてほしい。
- 制作者として、**動きが苦手なので、勝手に動かないでほしい**。
- 制作者として、**指で操作するとき、押し間違えない大きさ**が欲しい。
- 制作者として、**間違えても取り返せる**と分かっていたい。

## 2. 用語

- **代替情報**: 描画面以外の手段（一覧・数値・文章）で同じことを知る道。
- **常設**: その場に置かれ、必要なときに読める状態。
- **動きの抑制**: 自動で動く演出を控える設定。

## 3. 機能要件（FR）

### 3.1 描画面を唯一の出どころにしない（継承の核心）

- **FR-1** **状態・選択・範囲・警告・付与した情報は、必ず一覧・数値・文章でも確認できる**（系譜: 上流 §1-1）。**描画面はその一つの見せ方であって、唯一の出どころではない**。
- **FR-2** **すべての作業を、描画面に頼らず完了できる**（取り込み → 検品 → 整備 → 書き出し。系譜: 同上）。
- **FR-3** 代替情報は **常設**とする。**通知だけに頼らない**（系譜: 上流 §6。**流れて消える通知は、後から読み返せない**）。
- **FR-4** 描画面そのものにも **要約**を持たせる（何が表示されているか、主要な数値、警告の件数）。**詳細は隣の一覧で読める**（系譜: 同上）。
- **FR-5** 選択が変わったとき、**穏やかに通知**する（作業を妨げない形で。系譜: 同上）。

### 3.2 色だけに頼らない（継承）

- **FR-6** **すべての状態を、色だけで区別しない**（系譜: 上流 §1-5。**記号と文言を併用する**）。
- **FR-7** 分類（判定の目的など）も、**色と文字の併用**で示す（系譜: 上流 §6。`F-3D-07` FR-6 の目的表示と接続）。
- **FR-8** これは**制作物の側の規律とも一致する**（`F-2D-13` の色の制約 / 外部事例が示す「色が変わっても意味が失われない形」。**道具も作品も、色だけに意味を託さない**）。

### 3.3 操作の到達性

- **FR-9** **キーボードだけで一通り操作できる**（`F-3D-04` FR-3 が構造の探索で先に要件化したものを、横断へ広げる）。
- **FR-10** **指での操作に十分な大きさ**を確保する（系譜: 上流 §6 / 2D の規則）。
- **FR-11** **誤操作を防ぐ**（削除は確認を要し、**取り消せることを明示**する。系譜: 同上）。
- **FR-12** **ドラッグ中の意図しない接触は、ドラッグを優先**する（系譜: 同上。**操作の途中で別のことが起きない**）。

### 3.4 動きの抑制（継承）

- **FR-13** **動きを抑える設定を尊重**する（系譜: 上流 §6）。有効なとき、**自動回転・自動再生・滑らかな移動を止める**。
- **FR-14** 抑制時も **同じ情報へ到達できる**（動きが情報の唯一の伝達手段にならない。FR-1 と同じ思想）。

### 3.5 一貫性と拡張

- **FR-15** **2D と 3D で到達性の水準を揃える**（`S-DONE-3`。**片方だけ使える状態を作らない**）。
- **FR-16** **モジュールが提供する UI も、同じ到達性の要件に従う**（`F-UX-01` FR-9 / `A4`）。**足せるのは機能であって、例外ではない**。

### 3.6 確認できること

- **FR-17** 到達性は **確かめられる**（`F-PLT-04` の計測と同じく、**主張ではなく確認**にする）。**役割・名前・キーボード経路・代替情報の有無**を対象にする。
- **FR-18** **未確認の範囲を明示**する（`F-CORE-06` FR-7 / `F-PLT-04` FR-6 と同じ規律。**「対応済み」と言い切らない**）。

## 4. 非機能要件（NFR）

- **NFR-1（唯一の出どころにしない）**: 描画面なしで作業が完了する（FR-1/FR-2）。
- **NFR-2（読み返せる）**: 代替情報が常設（FR-3）。
- **NFR-3（色に依存しない）**: 記号と文言の併用（FR-6/FR-7）。
- **NFR-4（操作の到達性）**: キーボードと指の双方で使える（FR-9/FR-10）。
- **NFR-5（不意打ちのなさ）**: 勝手に動かない・誤操作しない（FR-11〜FR-13）。
- **NFR-6（水準の均一）**: 2D と 3D で差を作らない（FR-15）。
- **NFR-7（正直さ）**: 未確認を明示（FR-18）。

## 5. データ・保存への影響

- **保存データに影響しない**。
- 利用者の設定（動きの抑制・文字の大きさ等）を持つ場合、**編集データと分ける**（`adr/0007`）。
- 代替情報は **既存のデータから導く**（そのために新しい保存項目を増やさない）。

## 6. 依存機能

- **F-UX-01**（デザインシステム）: 作法の土台（FR-15/FR-16）。
- **F-2D-03 / F-3D-03**（各表示面）: 描画面を唯一にしない対象（FR-1/FR-4）。
- **F-3D-04**（構造検査）: キーボード探索と読み上げの先行例（FR-9）。
- **F-CORE-06**（検品）: 警告の代替表示（FR-1）。
- **F-UX-03**（メッセージ）: 文章の質（FR-3）。
- **F-UX-04**（端末対応方針）: 指の操作と画面差（FR-10）。
- **F-PLT-04**（計測）: 到達性の確認（FR-17）。

## 7. 受け入れ条件（Acceptance）

- **AC-1**: 状態・選択・範囲・警告・付与情報が、**一覧・数値・文章でも確認できる**（FR-1/NFR-1）。
- **AC-2**: **描画面に頼らず、取り込みから書き出しまで完了できる**（FR-2/NFR-1）。
- **AC-3**: 代替情報が**常設**であり、通知だけに頼らない（FR-3/NFR-2）。
- **AC-4**: 描画面に**要約**があり、詳細が隣で読める（FR-4）。
- **AC-5**: 選択の変化が**穏やかに通知**される（FR-5）。
- **AC-6**: **色だけで状態が区別されない**（FR-6/NFR-3）。
- **AC-7**: 分類が**色と文字の併用**で示される（FR-7）。
- **AC-8**: **キーボードだけで一通り操作できる**（FR-9/NFR-4）。
- **AC-9**: **指での操作に十分な大きさ**がある（FR-10/NFR-4）。
- **AC-10**: 削除が**確認を要し、取り消せることが明示**される（FR-11/NFR-5）。
- **AC-11**: **ドラッグ中の意図しない接触でドラッグが中断しない**（FR-12）。
- **AC-12**: **動きを抑える設定が尊重**され、自動の動きが止まる（FR-13/NFR-5）。
- **AC-13**: 抑制時も**同じ情報へ到達できる**（FR-14）。
- **AC-14**: **2D と 3D で到達性の水準が揃う**（FR-15/NFR-6）。
- **AC-15**: **モジュール提供の UI も同じ要件**に従う（FR-16）。
- **AC-16**: 到達性が**確かめられ**、**未確認の範囲が明示**される（FR-17/FR-18/NFR-7）。

## 8. 非目標

- 具体的な属性名・寸法・配色の確定（実装時に判断。**要件の枠だけ**を固定）。
- 特定の支援技術への最適化（**標準的な作法に従う**ことを優先）。
- 描画面の廃止（FR-1 は**併用**であって、視覚的な作業面を否定しない）。
- 完全準拠の宣言（FR-18。**確認した範囲だけを言う**）。
- 端末ごとの対応方針（**F-UX-04**）。
- メッセージの書き方（**F-UX-03**）。

## 10. Open questions

- 代替情報の粒度（どこまでを常設で出し、どこから要求に応じて出すか）。
- キーボード操作の網羅範囲（描画面の直接操作をどこまで代替するか）。
- 到達性の確認方法（自動でどこまで確かめられ、どこから人手か）。
- 動きの抑制が有効なときの、比較や再生の代替手段（`F-3D-12` と連動）。
- 利用者設定として持つ項目（濃淡・文字サイズ・抑制）。
