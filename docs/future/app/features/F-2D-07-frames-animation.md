## 0. 完成系での位置づけ（逆算リンク）

由来する完成系（`features/README.md` 2 章）:

- **D-DONE-4**: **フレームアニメーション**と簡易リグ焼き込みを扱える。
- **D-DONE-2**: レイヤー・パーツ・**フレーム**を整理できる。
- **D-DONE-7**: 対象別 preset と import notes つきで書き出せる。

逆算の理由: **F-2D-10（当たり判定）のフレーム上書きは、すでにフレームの存在を前提にしていた**。また `D-DONE-4` の中核であり、**制作物が「動く素材」になる**段である。

そして本機能には**外部と接する難所**がある——**表現力（可変時間・event）と、出力先の表現能力（固定 fps しか扱えない形式）が食い違う**。ここでの態度が、差別化仮説 2（「外部で確実に使える」）の質を決める。

関係マップのノード: `F-2D-04`（フレームが参照する構造）、`F-2D-10`（上書き単位の提供先）、`F-CORE-07`（書き出しとの衝突点）。

## 1. ユーザーストーリー

- 制作者として、**コマごとに表示時間を変えたい**（溜めは長く、attack は短く）。
- 制作者として、**同じ絵を使い回したい**（待機の往復など）。
- 制作者として、**特定のコマで効果音や判定のきっかけ**を出したい。
- 制作者として、**書き出したら勝手にタイミングが均されていた**——これが一番困る。
- 制作者として、**再生して確認しながら**調整したい。

## 2. 用語

- **Frame（フレーム）**: アニメーションの 1 コマ（表示内容の単位）。
- **出現（occurrence）**: あるアニメーション内でそのフレームが使われる 1 箇所。同じフレームが複数回出現しうる。
- **実効時間**: その出現が実際に表示される時間。
- **event**: フレームに紐づく通知（効果音・判定の合図など）。

## 3. 機能要件（FR）

### 3.1 フレーム

- **FR-1** フレームの**作成・複製・削除・並べ替え**ができる。
- **FR-2** フレームは **F-2D-04 の構造（レイヤー / パーツ）を参照**して表示内容を定める。
- **FR-3** **フレーム単体の複製**は、**内容と表示時間だけをコピー**し、**アニメーションの並び（参照）や event を変更しない**（系譜: ADR-0021）。複製したフレームの event は**明示的に作る**（黙って複製しない）。

### 3.2 可変時間（継承）

- **FR-4** アニメーションは**フレームの並び**で構成し、**同じフレームを複数のアニメーション／同一アニメーション内で再利用**できる。
- **FR-5** **フレームごとに表示時間を指定**できる（任意）。未指定なら**アニメーションの既定（fps 由来）**を使う。
- **FR-6** **実効時間 = フレームの指定があればそれ、なければ fps 由来**。**全体時間は各出現の実効時間の合計**（系譜: ADR-0021）。
- **FR-7** **同じフレームを再利用すると、全出現に同じ時間が適用**される。**出現ごとに違う時間が必要ならフレームを複製する**（系譜: ADR-0021）。
  **理由（継承）**: 出現ごとの上書きを許すと、**同じフレームが文脈によって違う意味を持つ**ことになる（`F-2D-10` FR-7 と同じ思想）。
- **FR-8** 表示用の**合計時間は informational**であり、**正本にしない・自動更新しない**（系譜: ADR-0021）。
- **FR-9** **再生・検査・書き出しが、同じ実効時間の規範を使う**（系譜: ADR-0021）。**各所が独自計算を持たない**（`F-2D-03` FR-8 の座標変換一元化と同じ思想）。

### 3.3 event（継承）

- **FR-10** フレームに **event を付けられる**。
- **FR-11** event は**そのフレームの表示開始時に発火**し、**各出現ごと・ループの各周回ごと**に発火する（系譜: ADR-0021）。
- **FR-12** 複製・反転などで ID が変わる場合、**event の ID を再採番し、参照先を完全に張り替える**（系譜: ADR-0021 / ADR-0002 の考え方）。
- **FR-13** **参照先を失った event（dangling）を意味検証で検出**する（F-CORE-06。黙って消さない・黙って直さない）。

### 3.4 書き出しとの衝突（今回の核心・継承）

- **FR-14** **可変時間や event を、固定 fps しか表現できない書き出しへ「黙って均一化・削除」しない**（系譜: ADR-0021）。
- **FR-15** その loss が起きる場合、該当する派生成果物を **理由つきで拒否**する（系譜: ADR-0021 の `H1=E1`）。
  **「利用者に確認したうえで均一化する」を既定として採らない**（系譜でも明示的に不採用）。**黙って劣化した成果物を外に出さない**ことを優先する。
- **FR-16** **loss の影響を受けない出力は許可**する（静止画・単体データ・プロジェクト形式など）。また、**そのアニメーションが参照していないフレームの指定だけでは、書き出しを止めない**（系譜: ADR-0021）。
- **FR-17** 拒否・警告の理由は**文章で示す**（何が表現できないのか、どうすれば出せるのか）（`S-DONE-4`）。

### 3.5 再生・確認

- **FR-18** **再生・停止・コマ送り・ループ**ができる。
- **FR-19** 再生が **UI を止めない**（`PF3`）。
- **FR-20** 操作は**履歴に乗り**（F-CORE-04）、**非破壊**である（F-CORE-03）。

## 4. 非機能要件（NFR）

- **NFR-1（意味の一貫性）**: 同じフレームは、**どのアニメーション経由でも同じ意味**を持つ（FR-7。`F-2D-10` NFR-2 と対）。
- **NFR-2（正直さ）**: **表現できないものを黙って劣化させない**（FR-14/FR-15）。
- **NFR-3（単一の規範）**: 実効時間の計算が一箇所に集約される（FR-9）。
- **NFR-4（非破壊）**: 遡及的な書き換えをしない（FR-3。失った情報を**勝手に復元しない**）。
- **NFR-5（応答性）**: 再生・編集が滑らか（FR-19）。

## 5. データ・保存への影響

- フレーム・アニメーション・event は**保存データの一部**（F-CORE-05 の器）。
- **フレームごとの時間指定は任意（additive）**とし、**未指定なら従来どおり fps 由来**として解釈する（系譜: ADR-0021 の「既存へ値を補完せず、fps-only の意味を変えない」）。**未指定を勝手に埋めない**。
- **合計時間は informational** であり、保存しても正本にしない（FR-8）。
- 再生位置・選択中フレームは **UI 一時状態**で保存に混ぜない（F-CORE-01 6 章）。

## 6. 依存機能

- **F-2D-04**（レイヤー & パーツ）: フレームが参照する構造（FR-2）。
- **F-2D-03**（Canvas）: 表示・操作面。
- **F-CORE-03 / 04**: 非破壊・履歴（FR-20）。
- **F-CORE-06**（検品）: dangling event 検出・出力検証（FR-13/FR-15）。
- **F-CORE-07 / F-2D-16**（書き出し）: loss 判定と拒否の実行点（FR-14〜FR-17）。
- **F-2D-10**（当たり判定）: フレーム上書きの単位を本機能が提供。
- **F-2D-08**（リグ焼き込み）: bake 先としてのフレーム。

## 7. 受け入れ条件（Acceptance）

- **AC-1**: フレームの作成・複製・削除・並べ替えができ、**複製が並びや event を変更しない**（FR-1/FR-3）。
- **AC-2**: **フレームごとに表示時間を指定**でき、未指定は fps 由来で解釈される（FR-5/FR-6）。
- **AC-3**: **同じフレームの全出現に同じ時間**が適用され、出現ごとに変えたい場合は複製が必要と示される（FR-7）。
- **AC-4**: **再生・検査・書き出しの時間計算が一致**する（FR-9/NFR-3）。
- **AC-5**: event が**各出現・各ループ周回で発火**する（FR-11）。
- **AC-6**: 複製・反転で **event の参照が正しく張り替わり**、**dangling が検出**される（FR-12/FR-13）。
- **AC-7**: **固定 fps しか扱えない書き出しで、可変時間や event が黙って均一化・削除されない**（FR-14）。
- **AC-8**: loss がある場合、該当成果物が **理由つきで拒否**され、**loss の無い出力は許可**される（FR-15/FR-16/FR-17）。
- **AC-9**: 未参照フレームの時間指定だけでは**書き出しが止まらない**（FR-16）。
- **AC-10**: 操作が履歴に乗り、**Source を変更しない**（FR-20/`G5`）。

## 8. 非目標

- **リグ・bake の仕組み**（`F-2D-08`）。本機能は bake 先のフレームを提供するのみ。
- 対象別 preset の中身（`F-2D-16`）。本機能は **loss の扱い方**だけを定める。
- 補間アニメーション（tween）やタイムライン曲線（本コンセプトの初期範囲外。必要ならモジュール）。
- 旧形式で失われた時間情報の**遡及復元**（系譜と同じく行わない）。
- 状態遷移（state machine）。
