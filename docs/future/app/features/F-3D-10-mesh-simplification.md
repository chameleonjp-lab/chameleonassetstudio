## 0. 完成系での位置づけ（逆算リンク）

由来する完成系:

- **T-DONE-6**: **元を壊さず**軽量化した別モデルを作り、前後を比較して選べる。
- **T-DONE-9**: 元の 3D モデルを絶対に上書きしない。

逆算の理由: 上流が言い切ったとおり、**3D 対応の価値の半分は軽量化**である（系譜: §15）。生成 3D や高品質モデルは、**そのままではゲームに入らない重さ**を持つことが多い。`F-3D-03` が「重い」と示した後、**実際に軽くする**のが本機能である。

そして完成系の文言そのものに設計が書かれている——**「元を壊さず」「別モデルを作り」「前後を比較して選べる」**。軽量化は**置き換えではなく、選択肢を増やす操作**である。

## 1. ユーザーストーリー

- 制作者として、**重いモデルを軽くしたい**。
- 制作者として、**軽くした結果が使えるかを、自分の目で見て決めたい**。
- 制作者として、**元のモデルを失いたくない**（軽くしすぎたらやり直したい）。
- 制作者として、**勝手に強く削られたくない**。
- 制作者として、**付けたアンカーや判定が壊れない**でほしい。
- 制作者として、**同じ設定なら同じ結果**になってほしい。

## 2. 用語

- **簡略化（simplification）**: 頂点・面の数を減らして軽くすること。
- **別モデル（optimized）**: 元とは別に作られた、軽量化済みのモデル。
- **破壊的最適化**: 元に戻せない形で構造を変える処理。

## 3. 機能要件（FR）

### 3.1 別モデルを作る（置き換えない — 継承の核心）

- **FR-1** 軽量化は **元とは別のモデルを作る**。**元モデルを置き換えない**（`G5` / `F-CORE-03`。系譜: 上流 §6「元ファイルを保持する」・T-DONE-6「元を壊さず」）。
- **FR-2** **元モデルはバイト不変**であり続ける（`F-3D-01` FR-10）。
- **FR-3** 別モデルは **何度でも作り直せる**。設定を変えて**複数の候補を持てる**（**一発勝負にしない**）。
- **FR-4** **軽量化した別モデルの採用は必須ではない**。**元のまま書き出せる**（系譜: 上流 §11「初期では optimized model は必須にしない」）。

### 3.2 強く削らない（既定を安全側へ — 継承）

- **FR-5** **初期・既定で、自動的に強い破壊的最適化をしない**（系譜: 上流 §6。**開いただけ・押しただけで形が変わらない**）。
- **FR-6** **削減の強さを制作者が選べる**（目標や段階として）。**「おまかせ」を既定にしない**。
- **FR-7** **見た目が変わる処理は、必ずプレビューしてから適用する**（系譜: 上流 §6 の明示。`F-2D-15` FR-9「修正案を自動確定しない」と同じ規律）。
- **FR-8** **安全に外せるもの（未使用データ・不要ノード）と、見た目に影響するもの（面の削減・統合）を区別**して示す（系譜: 上流 §6 の候補が「不要データ削除・ノード整理」と「マテリアル統合の検討」を並べていた前例。**性質が違うものを同じボタンにまとめない**）。

### 3.3 何が失われるかを示す

- **FR-9** 簡略化で**失われ得るもの**を示す（形状の細部・鋭い角・UV の連続性・法線・頂点属性など）。**「軽くなりました」だけにしない**。
- **FR-10** 数値の変化（頂点数・三角形数・ファイルサイズ）を示す（`F-3D-03` の検品項目と**同じ指標**で示し、別々の言い方をしない）。
- **FR-11** 前後の比較は **`F-3D-12`** に委ねる（本機能は候補を作り、**選ぶのは比較の側**）。

### 3.4 付与情報を壊さない（本コンセプト固有）

- **FR-12** 簡略化しても、**`F-3D-05` の基準（原点・向き・スケール）が変わらない**。
- **FR-13** 簡略化しても、**`F-3D-06` のアンカーと `F-3D-07` の判定が保持され、作り直しを要さない**。
  - これは **`F-3D-07` が形状を box / sphere / capsule に限定した利点**でもある。**判定がモデルの形に依存していないため、面を減らしても判定は影響を受けない**。
- **FR-14** 保持できない場合は、**理由つきで示す**（黙って落とさない。`F-CORE-06`）。

### 3.5 実行と再現性

- **FR-15** 簡略化は **決定的**である（同じ入力・同じ設定で同じ結果。`F-2D-12` FR-6 / `F-3D-03` FR-15 と同じ）。
- **FR-16** 重い処理は **UI から逃がす**（`PF3` / `F-PLT-03`）。**進行を表示**し、**取消できる**。
- **FR-17** **失敗・取消で、プロジェクトを変更しない**（`F-2D-11` FR-14 / `F-3D-01` FR-8 と同じ原子性）。
- **FR-18** 外部ライブラリの採用は **ライセンス検証ゲート**を通る（`G1` / `F-MOD-04`）。**候補の提示と採用は別**である。

## 4. 非機能要件（NFR）

- **NFR-1（非破壊）**: 元モデルが不変で、別モデルとして作る（FR-1/FR-2。`G5`）。
- **NFR-2（安全側の既定）**: 勝手に強く削らない（FR-5/FR-6）。
- **NFR-3（見てから決める）**: 見た目が変わる処理はプレビューが先（FR-7）。
- **NFR-4（正直さ）**: 失われ得るものを示す（FR-9/FR-14）。
- **NFR-5（付与情報の保全）**: アンカー・判定・基準が壊れない（FR-12/FR-13）。
- **NFR-6（決定性）**: 同じ設定に同じ結果（FR-15）。
- **NFR-7（原子性）**: 失敗が何も壊さない（FR-17）。

## 5. データ・保存への影響

- **元モデルは Source として不変**（FR-2）。**別モデルは派生**として保持する（`F-CORE-03`）。
- 軽量化の**設定（レシピ）を保存し得る**——同じ結果を再生成できるように（FR-15）。保存は additive / 名前空間分離（`D4`）。
- **アンカー・判定・基準は元の付与情報を正本**とし、別モデルごとに複製しない（**同じ意味の情報を二重に持たない**。`F-2D-12` FR-4 と同じ）。
- 書き出しに別モデルを含めるかは **`F-3D-15` の判断**（FR-4）。

## 6. 依存機能

- **F-3D-01**（安全読み込み）: 元モデルの供給と verbatim 保持。
- **F-3D-03**（検品表示）: 重さの指標（FR-10）。
- **F-3D-05 / 06 / 07**（基準・アンカー・判定）: 保全対象（FR-12/FR-13）。
- **F-3D-12**（前後比較）: 採用可否の判断面（FR-11）。
- **F-3D-11**（テクスチャ圧縮）: 軽量化のもう一つの軸。
- **F-PLT-03**（offload）: 重い処理（FR-16）。
- **F-CORE-03 / 04**: 非破壊・履歴。
- **F-MOD-04**（ライセンス検証）: 外部ライブラリの門（FR-18）。
- **F-3D-15**（書き出し）: 別モデルの同梱可否（FR-4）。

## 7. 受け入れ条件（Acceptance）

- **AC-1**: 軽量化が **別モデルとして作られ**、元を置き換えない（FR-1/NFR-1）。
- **AC-2**: 軽量化後も **元モデルがバイト不変**（FR-2）。
- **AC-3**: 設定を変えて**複数の候補を持てる**（FR-3）。
- **AC-4**: **軽量化を採用せず、元のまま書き出せる**（FR-4）。
- **AC-5**: **既定で強い破壊的最適化が起きない**（FR-5/NFR-2）。
- **AC-6**: **見た目が変わる処理が、プレビューなしに適用されない**（FR-7/NFR-3）。
- **AC-7**: **安全に外せるものと、見た目に影響するものが区別**して示される（FR-8）。
- **AC-8**: **失われ得るものが示される**（FR-9/NFR-4）。
- **AC-9**: 数値の変化が **`F-3D-03` と同じ指標**で示される（FR-10）。
- **AC-10**: 簡略化後も **基準・アンカー・判定が保持され、作り直しを要さない**（FR-12/FR-13/NFR-5）。
- **AC-11**: 保持できない場合に**理由つきで示される**（FR-14）。
- **AC-12**: 同じ設定で**同じ結果**になる（FR-15/NFR-6）。
- **AC-13**: 重い処理で **UI が固まらず、進行が見え、取消できる**（FR-16）。
- **AC-14**: 失敗・取消で**プロジェクトが変わらない**（FR-17/NFR-7）。
- **AC-15**: 外部ライブラリが**ライセンス検証を通らずに入らない**（FR-18）。

## 8. 非目標

- **自動での強い最適化**（FR-5。**「おまかせで最軽量」は作らない**）。
- 簡略化アルゴリズムの確定（実装時に判断。**決定性と非破壊という要件だけ**を固定）。
- テクスチャの圧縮（**F-3D-11**）。
- 前後比較の面（**F-3D-12**）。
- モデルの再作成・リトポロジ（**整えるのであって作り直すのではない**）。
- 採用ライブラリの選定（`G1` の評価が先。候補名を採用として書かない）。
