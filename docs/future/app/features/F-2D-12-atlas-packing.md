## 0. 完成系での位置づけ（逆算リンク）

由来する完成系:

- **D-DONE-5**: tileset / sprite sheet を再整理し、**atlas に詰められる**。
- **D-DONE-7**: 対象エンジンで**そのまま使える形**で書き出せる。

逆算の理由: `F-2D-11` が**切り分け（ばらす）**側、本機能が**詰め直し（まとめる）**側であり、2 つで `D-DONE-5` の対になる。ゲーム側の実利（描画コール削減・ファイル数削減）が目的であり、**制作データの都合ではなく出力の都合**で行う工程である。

したがって本機能の最重要要件は「どう詰めるか」ではなく、**「詰めても、制作データの意味が一切変わらない」** ことである。

## 1. ユーザーストーリー

- 制作者として、**複数のコマを 1 枚のシートにまとめて**書き出したい。
- 制作者として、まとめても**原点・アンカー・当たり判定がずれない**と確信したい。
- 制作者として、**同じ入力なら毎回同じ結果**になってほしい（差分・再現性）。
- 制作者として、**シートに収まらない**なら、黙って切り捨てず**理由を知りたい**。
- 制作者として、**まとめた結果を、あとで読み直せる範囲**を知りたい。

## 2. 用語

- **atlas / sheet**: 複数のコマを 1 枚の画像に配置したもの。
- **セル（cell）**: 等サイズの区画。**セル単位配置**は各コマを同じ大きさの枠に置く方式。
- **trim**: 各コマの透明な余白を削って詰める方式。
- **パススルー**: 制作データの値を**変換せずそのまま**出力へ運ぶこと。

## 3. 機能要件（FR）

### 3.1 出力層の境界（継承 — 最重要）

- **FR-1** **atlas 化・trim・出力倍率は「出力層の操作」**であり、**共通アセット座標・キャンバスサイズ・原点 / アンカー / 当たり判定の保存値を変更しない**（系譜: ADR-0004 の決定そのもの）。
- **FR-2** 原点 / アンカー / 当たり判定は、**変換や trim オフセット補正を行わずパススルー**する（系譜: ADR-0004）。**出力の都合で判定を作り直さない**。
- **FR-3** **出力倍率（1x / 2x / 3x 等）は出力側の scale として扱い**、共通データの座標を変えない（系譜: ADR-0004）。
- **FR-4** 出力の設定項目を足す場合、**既存の設定へ配線し、重複する新項目を作らない**（系譜: ADR-0004 が `ExportPreset.scale` について明示した規律。**同じ意味の設定を二重に持たない**）。

### 3.2 配置（レイアウト）

- **FR-5** 既定は **セル単位の配置**（trim なし・回転なし）とする（系譜: ADR-0004 の現行規範）。**まず確実に正しい方式**を既定に置く。
- **FR-6** 配置は **決定的**である。**同じ入力・同じ設定なら、毎回同じ位置**になる（差分が安定し、再現できる）。
- **FR-7** 配置結果は **シート内の絶対座標として自己記述**される（どのコマがどこにあるかが、外部から曖昧さなく読める）。
- **FR-8** **並び順が意味を持つ場合（フレーム順など）、順序を壊さない**（`F-2D-07` のフレーム列と整合させる）。
- **FR-9** **シート上限（サイズ・枚数）に収まらない場合、黙って切り捨てず、理由つきで拒否または分割**する（`F-CORE-06` の出力検証／`F-CORE-07` の loss 規律と同じ）。

### 3.3 trim / 回転を有効にする場合の条件（継承 — ゲート）

- **FR-10** **trim を有効にする出力は、次の 4 記録を必須**とする（系譜: ADR-0004 の要求をそのまま継承）:
  1. **trim 前の元フレームサイズ**
  2. **切り出した矩形の位置とサイズ**
  3. **atlas 内に置いた位置とサイズ**
  4. **元の原点 / アンカー / 当たり判定を復元するための変換情報**
- **FR-11** 上記 4 記録を**満たせない trim 実装を有効にしない**。**「ファイルが小さくなる」ことは、判定がずれる理由にならない**。
- **FR-12** **atlas 内の画像回転は既定で使わない**（系譜: ADR-0004）。有効にする場合も FR-10 と同じ復元可能性を条件にする。
- **FR-13** trim / 回転の有効化は、**対象エンジンごとの変換確認を先に行う**（系譜: ADR-0004 の再検討条件。`F-2D-15` の適合チェックと接続）。

### 3.4 読み直しとの境界

- **FR-14** 本機能の出力は **`F-2D-11` の「自形式シートの読み直し」の入力**になり得るが、それは **「配布物を元のプロジェクトへ戻す操作ではない」**（系譜: ADR-0018。`F-2D-11` FR-8）。
- **FR-15** **すべての出力が読み直せるとは表現しない**（`F-2D-11` FR-13 と同じ）。読み直せる構成の条件を、出力側でも**明示**する。

### 3.5 実行と検証

- **FR-16** 大量フレームの配置・書き出しは **UI から逃がす**（`PF3` / `F-PLT-03`）。**キャンセルで中途半端な出力を残さない**。
- **FR-17** 出力前に **参照の解決・配置の妥当性を検証**する（`F-CORE-06` の出力検証）。**未解決参照や不整合を黙って落とさない**。
- **FR-18** 出力は **`F-CORE-07` の書き出しフレーム**に載る（独自の書き出し経路を作らない）。

## 4. 非機能要件（NFR）

- **NFR-1（不変性）**: 詰めても制作データの座標・判定が変わらない（FR-1/FR-2/FR-3）。
- **NFR-2（再現性）**: 同じ入力が同じ結果になる（FR-6）。
- **NFR-3（正直さ）**: 収まらない・戻せない・読み直せないを事前に示す（FR-9/FR-15）。
- **NFR-4（自己記述性）**: 出力だけを見て配置が判る（FR-7）。
- **NFR-5（応答性）**: 大量フレームでも UI を固めない（FR-16。`PF3`）。
- **NFR-6（単一表現）**: 同じ意味の設定を二重に持たない（FR-4）。

## 5. データ・保存への影響

- **保存データに影響を与えない**。atlas は**出力成果物**であり、`F-CORE-05` の保存内容を変えない（FR-1）。
- 配置設定（セルサイズ・上限・並び）は **書き出し設定**として持つ（`F-2D-16` / `F-CORE-07`）。**編集データに混ぜない**。
- trim を将来有効にする場合、**4 記録は出力側のメタ**として持つ（保存データ側の座標は変えない。FR-10）。

## 6. 依存機能

- **F-2D-11**（tileset / sprite sheet 整理）: 入力（整理済みのコマ）。
- **F-2D-07**（フレーム）: 並び順の正本（FR-8）。
- **F-2D-09 / F-2D-10**（原点・アンカー / 当たり判定）: パススルー対象（FR-2）。
- **F-CORE-07**（書き出しフレーム）: 出力の器（FR-18）。
- **F-CORE-06**（検品）: 出力検証（FR-17）。
- **F-2D-16**（書き出し preset）: 設定の置き場（FR-4）。
- **F-2D-15**（2D 検品）: エンジン適合確認（FR-13）。
- **F-PLT-03**（offload）: 大量処理（FR-16）。

## 7. 受け入れ条件（Acceptance）

- **AC-1**: atlas 化しても、**原点 / アンカー / 当たり判定の保存値が変わらない**（FR-1/NFR-1）。
- **AC-2**: それらが**変換されずパススルー**され、出力側で判定がずれない（FR-2）。
- **AC-3**: **出力倍率が保存座標を変えない**（FR-3、`F-2D-06` AC-5 と同じ規律）。
- **AC-4**: 同じ入力・同じ設定で**毎回同じ配置**になる（FR-6/NFR-2）。
- **AC-5**: 出力から**各コマの位置が曖昧さなく読める**（FR-7/NFR-4）。
- **AC-6**: **順序が意味を持つ場合に順序が保たれる**（FR-8）。
- **AC-7**: 収まらない場合に**黙って切り捨てず、理由が示される**（FR-9/NFR-3）。
- **AC-8**: **trim を有効にする出力が、4 記録なしには成立しない**（FR-10/FR-11）。
- **AC-9**: **回転が既定で使われない**（FR-12）。
- **AC-10**: 「読み直し」が**元に戻す操作ではない**と示され、**すべてが読み直せるとは表現されない**（FR-14/FR-15）。
- **AC-11**: 大量フレームで**キャンセルしても中途半端な出力が残らない**（FR-16、`F-PLT-03` AC-3 と対）。
- **AC-12**: 未解決参照・不整合が**黙って落ちない**（FR-17）。
- **AC-13**: 同じ意味の設定が**二重に存在しない**（FR-4/NFR-6）。

## 8. 非目標

- **最密充填の追求**（詰め込み効率よりも、意味の保存と再現性を優先する。FR-5/FR-6）。
- **trim / 回転の既定有効化**（FR-10 の 4 記録と FR-13 の確認が先。ゲートであり禁止ではない）。
- 外部 atlas 形式（TexturePacker 等）の**読み込み**（`F-2D-11` 非目標と同じ。必要なら別判断 + ライセンス評価 `G1`）。
- 配布物からのプロジェクト**完全復元**（FR-14 で明確に否定）。
- タイルマップ（配置）の編集（`F-2D-11` 非目標と同じ）。
- 対象エンジンごとの preset の中身（**F-2D-16**）。
