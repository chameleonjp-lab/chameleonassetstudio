## 0. 完成系での位置づけ（逆算リンク）

由来する完成系:

- **T-DONE-3**: ファイルサイズ・ポリゴン数・マテリアル・テクスチャ・bounds・妥当性を**検品できる**。
- **T-DONE-6**: 元を壊さず軽量化した別モデルを作れる（**その判断材料**を供給する）。

逆算の理由: `F-3D-03` は **「重いか軽いか」の概観**を担う。しかし「三角形数が多い」と言われても、**どこが多いのかが判らなければ直せない**。本機能は **「モデルの中身」** を開き、**問題箇所を特定できる**ようにする。

そして本機能は `F-3D-10`（軽量化）の前提でもある。**「安全に外せるもの（未使用データ・不要ノード）」と「見た目に影響するもの」を区別する**（`F-3D-10` FR-8）には、**何が未使用で、何が重複しているかを知る手段**が要る。

## 1. ユーザーストーリー

- 制作者として、**モデルの中身がどうなっているか**を見たい。
- 制作者として、**問題があると言われた箇所へ、すぐ行きたい**。
- 制作者として、**どれが未使用か・重複しているか**を知りたい。
- 制作者として、**一部だけ隠して確認したい**（ただし保存内容は変えたくない）。
- 制作者として、**警告が「ゲームで何が起きるか」まで教えてほしい**。
- 制作者として、**自分の用途では無視してよい警告**を知りたい。

## 2. 用語

- **構造（scene graph）**: モデル内部の要素の入れ子関係。
- **要素**: 節点・形状・材質・画像など、モデルを構成する単位。
- **未使用**: 参照されていない要素。
- **検査版**: どの版の検査規則で調べたかを表す識別。

## 3. 機能要件（FR）

### 3.1 中身を見る

- **FR-1** モデルの**構造を階層として表示**する（複数の場面を含む場合も扱う。系譜: 上流 `3D-STAGE2-02`）。
- **FR-2** **形状・材質・画像などを一覧**できる（系譜: 同上）。
- **FR-3** **検索**でき、**キーボードだけでも辿れる**（系譜: 同上。`F-UX-02` と接続）。
- **FR-4** **選択が `F-3D-03` の表示と連動**する（一覧で選ぶと画面上で強調され、逆も同じ。系譜: 同上）。
- **FR-5** **選択した内容が読み上げに載る**（系譜: 同上の aria-live 通知。`F-UX-02`）。

### 3.2 一時的な表示操作（保存を変えない）

- **FR-6** 要素の**表示 / 非表示を切り替えられる**（隠して中を見る）。
- **FR-7** **表示 / 非表示は一時状態であり、保存データに書かない**（系譜: 同上「表示切替は保存データに書かないでください」。`F-CORE-01` 6 章 / `F-2D-03` と同じ規律）。
- **FR-8** 表示操作を含め、**本機能のすべての操作が read-only** である（`F-3D-03` FR-13 / ADR-0014）。

### 3.3 詳細な検査

- **FR-9** 概観（`F-3D-03`）より**細かい単位で検査**する（幾何・UV・材質・透明の扱い・両面表示・スキン・変形・節点・拡張・光・カメラなど。系譜: 上流 `3D-STAGE2-04`）。
- **FR-10** **問題箇所へジャンプできる**（形状・材質の単位で。系譜: 同上。**これが概観との本質的な差**——`F-3D-03` は「重い」と言い、本機能は「どこが」を示す）。
- **FR-11** **未使用・重複を検出**する（`F-3D-10` の「安全に外せるもの」の判定根拠を供給）。
- **FR-12** **自動修正しない**（系譜: 上流 `3D-STAGE2-04`「非範囲 = 自動修正」。`F-2D-15` FR-9 / `F-3D-10` FR-5 と同じ規律）。

### 3.4 警告の中身（継承 — 上流の警告構造）

各警告は、少なくとも次を伴う（系譜: 上流 §4.2 の警告フィールド）:

- **FR-13** **どの検査によるものか**（検査の識別）と、**深刻度の区別**（情報 / 警告 / 拒否）。
- **FR-14** **対象**（種別・位置・名前）。**「どこが」を必ず持つ**（FR-10 の裏づけ）。
- **FR-15** **実測値と推奨値**、および**どの対象環境プリセットに対する評価か**（`F-3D-03` FR-9/FR-10）。
- **FR-16** **理由**（なぜ問題か）。
- **FR-17** **ゲームで何が起きるか**（系譜: 同上 `gameImpact`。**「三角形数が多い」ではなく「低性能端末で描画が落ちる可能性がある」**まで言う）。
- **FR-18** **どうすれば直るか**、および **このアプリで直せるか**（系譜: 同上 `fix` / `fixableInChameleon`。**直せないものを直せるかのように見せない**）。
- **FR-19** **無視してよい条件**（系譜: 同上 `ignorableWhen`。**「PC 専用で低性能端末を対象に含めないなら無視してよい」**のように書く）。
  - これは `F-3D-03` FR-11 が置いた課題——**厳しすぎて無視される基準は、基準として機能しない**——への回答である。**無視してよい条件を書いておけば、無視は「規律ある判断」になり、警告の信用が保たれる**。
- **FR-20** **検査版を結果に含める**（系譜: 同上 `inspectionVersion`。**検査規則が変われば結果も変わる**ことを追跡できる）。

### 3.5 検査対象と再実行（継承）

- **FR-21** 検査は **元のバイト列に対して行う**（系譜: 上流 §4.1）。
- **FR-22** **派生（軽量化後など）に対しては、同じ検査を再実行して比較できる**（系譜: 同上。`F-3D-12` の数値差の供給元）。**別の物差しで比べない**。
- **FR-23** 検査結果は **`F-3D-14`（inspection report）と `F-3D-15`（書き出し）の入力**になる。**画面の結果と成果物の結果が一致する**（`F-3D-03` FR-14 と同じ）。

### 3.6 実行

- **FR-24** 検査は **決定的**である（同じ入力・同じ検査版・同じプリセットに同じ結果。`F-3D-03` FR-15）。
- **FR-25** 大きなモデルの構造展開・検査で **UI を固めない**（`PF3` / `F-PLT-03`）。**秒単位の処理に例外を作らない**（`F-3D-11` FR-16a と同じ）。
- **FR-26** しきい値・上限値は **`F-3D-03` と同じ所在を参照**する。**二重に持たない**（`F-3D-03` FR-11a）。

## 4. 非機能要件（NFR）

- **NFR-1（特定できる）**: 「どこが」問題かへ到達できる（FR-10/FR-14）。
- **NFR-2（read-only）**: 見ても隠しても保存が変わらない（FR-7/FR-8。`G5`）。
- **NFR-3（行動につながる）**: 影響・直し方・無視してよい条件まで伴う（FR-17〜19）。
- **NFR-4（自動修正しない）**: 判断は制作者（FR-12）。
- **NFR-5（一貫性）**: 同じ物差し・同じ所在のしきい値（FR-22/FR-26）。
- **NFR-6（決定性）**: 同じ入力に同じ結果（FR-24）。
- **NFR-7（到達性）**: キーボードと読み上げで使える（FR-3/FR-5）。
- **NFR-8（応答性）**: 大きなモデルで固まらない（FR-25）。

## 5. データ・保存への影響

- **保存データを変更しない**（FR-8）。
- **表示 / 非表示・選択・展開状態は UI 一時状態**であり保存しない（FR-7）。
- **検査結果は記録し得る**（`F-3D-14` の素）。**検査版とプリセットを添えて**記録する（FR-15/FR-20）。additive / 名前空間分離（`D4`）。
- しきい値の確定値は**一つの所在**に置く（FR-26。`F-3D-03` FR-11a/11b）。

## 6. 依存機能

- **F-3D-01**（安全読み込み）: 検査対象の供給と元バイト列の保持（FR-21）。
- **F-3D-03**（ビューポート & 検品表示）: 概観・表示面・プリセット（FR-4/FR-15/FR-26）。
- **F-CORE-06**（検品フレーム）: 三段検証の正本。本機能は**意味検証の 3D 具体**（`F-3D-03` FR-12 と同じ枠に載る）。
- **F-3D-10**（軽量化）: 未使用・重複の情報を供給（FR-11）。
- **F-3D-12**（前後比較）: 派生の再検査結果を供給（FR-22）。
- **F-3D-14 / 15**（report / 書き出し）: 結果の利用先（FR-23）。
- **F-UX-02**（アクセシビリティ）: キーボード・読み上げ（FR-3/FR-5）。
- **F-PLT-03**（offload）: 重い展開・検査（FR-25）。

## 7. 受け入れ条件（Acceptance）

- **AC-1**: 構造を**階層として辿れ**、形状・材質・画像を**一覧できる**（FR-1/FR-2）。
- **AC-2**: **検索でき、キーボードだけでも辿れる**（FR-3/NFR-7）。
- **AC-3**: **一覧の選択と画面の強調が連動**する（FR-4）。
- **AC-4**: 選択内容が**読み上げに載る**（FR-5/NFR-7）。
- **AC-5**: **表示 / 非表示を切り替えても保存データが変わらない**（FR-6/FR-7/NFR-2）。
- **AC-6**: 概観より**細かい単位で検査**され、**問題箇所へジャンプできる**（FR-9/FR-10/NFR-1）。
- **AC-7**: **未使用・重複が検出**され、`F-3D-10` の判定根拠になる（FR-11）。
- **AC-8**: **自動修正が行われない**（FR-12/NFR-4）。
- **AC-9**: 各警告が **対象・実測値・推奨値・プリセット・理由**を持つ（FR-14/FR-15/FR-16）。
- **AC-10**: 各警告が **ゲームで何が起きるか**を示す（FR-17/NFR-3）。
- **AC-11**: 各警告が **直し方**と **このアプリで直せるか**を示す（FR-18）。
- **AC-12**: 各警告が **無視してよい条件**を示す（FR-19、`F-3D-03` FR-11 の課題への回答）。
- **AC-13**: 結果に**検査版**が含まれる（FR-20）。
- **AC-14**: 派生に対して**同じ検査を再実行して比較**できる（FR-22/NFR-5）。
- **AC-15**: **画面の結果と成果物の結果が一致**する（FR-23）。
- **AC-16**: 同じ入力・同じ検査版・同じプリセットで**同じ結果**（FR-24/NFR-6）。
- **AC-17**: 大きなモデルで **UI が固まらない**（FR-25/NFR-8）。
- **AC-18**: しきい値が **`F-3D-03` と同じ所在**を参照し、二重に存在しない（FR-26）。

## 8. 非目標

- **構造の編集**（階層の組み替え・名称変更）。系譜: 上流 `3D-STAGE2-02`「非範囲 = 階層編集・名称変更」。**整えるのであって、作り変えるのではない**。
- **自動修正**（FR-12）。
- 検査項目の網羅（対象と用途に応じて育てる。**警告の構造だけ**を固定する）。
- 概観の指標（**F-3D-03**）。
- 軽量化の実行（**F-3D-10** / **F-3D-11**）。
- report の形式（**F-3D-14**）。
- 骨格の詳細検査（**F-3D-08**。`APP-O-04` の判断待ち）。
