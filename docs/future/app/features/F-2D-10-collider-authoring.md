## 0. 完成系での位置づけ（逆算リンク）

由来する完成系（`features/README.md` 2 章）:

- **D-DONE-3**: 原点・アンカー・**当たり判定（rect / circle / polygon）** を付けられる。
- **D-DONE-6**: 「エンジンで使える状態か」を検品できる。

逆算の理由: 当たり判定は **ゲームの挙動を直接左右する情報**であり、**間違っていても見た目では気づきにくい**。だからこそ、**編集しやすさと同じくらい「壊れにくさ」が要る**。

本機能は `F-2D-09`（原点・アンカー）と対になる `D-DONE-3` の後半である。

関係マップのノード: `F-2D-03`（座標の正本）、`F-2D-04`（付与先）、`F-CORE-06`（検品）、`G3 差別化仮説`。

## 1. ユーザーストーリー

- 制作者として、**攻撃判定と被弾判定を分けて**付けたい。
- 制作者として、**フレームごとに判定を変え**たい（攻撃の瞬間だけ判定を伸ばす等）。
- 制作者として、判定を**見ながら**調整したい。
- 制作者として、**反転コピーで判定が左右おかしくならない**でほしい。
- 制作者として、**複雑な形**が必要なとき（凹んだ形状）に手段がほしい。

## 2. 用語

- **collider**: 当たり判定の図形（rect / circle / polygon）。
- **purpose（用途）**: その判定が何のためか（攻撃・被弾・接地判定など）。
- **アセット共通の判定**: そのアセット全体に効く既定の判定。
- **フレーム上書き**: 特定フレームでだけ位置・サイズ等を変えること。

## 3. 機能要件（FR）

### 3.1 基本

- **FR-1** **rect / circle** の判定を追加・編集・削除できる（第一級サポート）。
- **FR-2** 各判定に **purpose（用途）** を設定できる（攻撃・被弾など、外部で意味を持つ区分）。
- **FR-3** 判定は **共通アセット座標**で保持する（ADR-0001 / `F-2D-03` FR-6）。
- **FR-4** canvas 上で**見ながら編集**でき、**表示/非表示を切り替え**られる（`F-2D-03` の基盤）。
- **FR-5** 付与操作は**履歴に乗り**（F-CORE-04）、**非破壊**である（F-CORE-03）。

### 3.2 上書きの単位と範囲（継承 — 重要）

- **FR-6** 判定の**正本はアセット共通**とする（系譜: ADR-0010）。
- **FR-7** **上書きはフレーム単位のみ**とし、**アニメーション単位の上書きを導入しない**（系譜: ADR-0010）。
  **理由（継承）**: 同じフレームを複数のアニメーションが共有しうる構造では、アニメーション単位の上書きを許すと「**どのアニメーション経由で表示されたかで同じフレームの判定が変わる**」ことになり、**フレームという単位の意味が分裂する**。
- **FR-8** 優先順位は **フレーム上書き > アセット共通**（系譜: ADR-0010）。
- **FR-9** **上書きで変えられる範囲を限定**する: **位置・サイズ・表示可否のみ**。**判定の追加・削除、purpose 変更、形状（shape）変更は上書きで行えない**（系譜: ADR-0010）。上書き対象はアセット共通に既存の判定に限る。

### 3.3 polygon の扱い（チェックリストの継承）

- **FR-10** polygon は `D-DONE-3` の範囲に含む。ただし **「入れる」と決める前に、次をすべて決め切る**（系譜: ADR-0010 が polygon 導入前に要求したチェックリストを、本コンセプトでも**同じ厳しさで**適用する）:
  - 点の座標系（**絶対値か相対値か**）
  - **最小点数・自己交差の可否・凸/凹の扱い・頂点順の規則**
  - **左右反転後の頂点順**（`F-2D-09` FR-11 / ADR-0005 と整合するか）
  - **schema / migration / helper / 書き出し / 対象別 adapter / テスト**への影響
  - 既存の **rect / circle との併存**と、過去データとの互換
- **FR-11** 上記が**未決のまま polygon を有効にしない**。有効化は**人間承認**を伴う（`APP_ROADMAP_DECISIONS_OPEN_ITEMS.md` の open item として扱う）。
- **FR-12** polygon が無効の間も、**rect / circle だけで一続きの制作が完了**する（行き止まりを作らない）。

### 3.4 反転との整合

- **FR-13** **左右反転**で判定が**規則どおりに反転**する（系譜: ADR-0005 の反転式の考え方。rect は矩形の左右位置、circle は中心 x を鏡映）。
- **FR-14** フレーム上書きがある場合、**上書き座標も同じ反転規則に従う**（系譜: ADR-0010）。

### 3.5 検証

- **FR-15** **判定が無い / 明らかに不正（サイズ 0・範囲外）** を検出する（F-CORE-06 の意味検証）。
- **FR-16** 書き出し時、**対象が対応していない判定形状**（例: polygon を扱えない preset）を**警告または停止**する（F-CORE-06 の出力検証 / `F-2D-16`）。**黙って落とさない**。

## 4. 非機能要件（NFR）

- **NFR-1（壊れにくさ）**: 上書き範囲の限定（FR-9）により、**意図しない構造変更が起きない**。
- **NFR-2（意味の一貫性）**: 同じフレームは、**どの経路で表示されても同じ判定**になる（FR-7 の帰結）。
- **NFR-3（正確さ）**: 画面で描いた判定と保存座標が一致する（`F-2D-03` NFR-2）。
- **NFR-4（非破壊）**: 付与が Source を変更しない（`G5`）。
- **NFR-5（明快さ）**: 判定と用途が見て区別できる（FR-2/FR-4）。

## 5. データ・保存への影響

- 判定は**保存データの一部**（F-CORE-05 の器）。**アセット共通が正本**、**フレーム上書きは任意の追加情報**として持つ（FR-6/FR-7）。
- **上書きは additive**（既存を壊さない追加）として扱い、**未対応環境では無視されても正本が成立**する（`D3` 未知データ非破壊と整合）。
- polygon を将来有効化する場合、**形状の追加は保存契約に影響する**ため、F-CORE-05 の版・移行の判断を通す（FR-10/FR-11）。

## 6. 依存機能

- **F-2D-03**（Canvas）: 座標の正本・描画操作。
- **F-2D-04**（レイヤー & パーツ）: 付与先の単位。
- **F-2D-07**（フレーム）: フレーム上書きの単位（FR-7）。
- **F-CORE-03 / 04**: 非破壊・履歴。
- **F-CORE-05**（保存形式）: 上書きの持ち方・将来の形状追加。
- **F-CORE-06**（検品）: 不正検出・出力検証（FR-15/FR-16）。
- **F-2D-16**（書き出し preset）: 対象ごとの対応可否（FR-16）。

## 7. 受け入れ条件（Acceptance）

- **AC-1**: rect / circle を追加・編集・削除でき、**purpose を設定**できる（FR-1/FR-2）。
- **AC-2**: **フレーム単位の上書き**ができ、**アニメーション単位の上書きが存在しない**（FR-7）。
- **AC-3**: 同じフレームが、**どのアニメーション経由でも同じ判定**になる（NFR-2）。
- **AC-4**: 上書きで**位置・サイズ・表示可否のみ**が変わり、**追加・削除・purpose・形状は変えられない**（FR-9）。
- **AC-5**: **左右反転で判定が規則どおり反転**し、**上書き座標も同じ規則に従う**（FR-13/FR-14）。
- **AC-6**: 画面で描いた判定と**保存座標が一致**する（NFR-3）。
- **AC-7**: **polygon はチェックリストが未決の間、有効にならない**。その間も **rect / circle だけで制作が完了**できる（FR-11/FR-12）。
- **AC-8**: 対象が扱えない形状は、書き出し時に**警告または停止**し、**黙って落とされない**（FR-16）。

## 8. 非目標

- **polygon の採否・仕様の確定**（FR-10 のチェックリスト完了 + 人間承認が必要）。
- 物理シミュレーション（本コンセプトは判定情報を**付与**するツールであり、実行しない）。
- 3D の当たり判定（`F-3D-07`）。
- 対象エンジンごとの判定変換（`F-2D-16` / F-CORE-07）。
- 自動判定生成（輪郭からの自動生成は将来の別機能／モジュール候補）。
