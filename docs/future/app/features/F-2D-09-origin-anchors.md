## 0. 完成系での位置づけ（逆算リンク）

由来する完成系（`features/README.md` 2 章）:

- **D-DONE-3**: **原点・アンカー**・当たり判定を付けられる。
- **D-DONE-7**: 対象別 preset と import notes つきで書き出せる（＝付けた情報が**外部で意味を持つ**）。

逆算の理由: ここは **「絵」を「ゲーム素材」に変える最初の一歩**である。同じ PNG でも、**原点がどこか**で配置結果は変わり、**アンカーがあるか**で武器やエフェクトを正しく付けられるかが決まる。

差別化仮説 2（「外部エンジンで確実に使える状態か」）は、**この情報が正確に付き、正確に書き出される**ことに依存している。

関係マップのノード: `F-2D-03`（座標の正本と操作面）、`F-CORE-07`（書き出し先）、`G3 差別化仮説`。

## 1. ユーザーストーリー

- 制作者として、**キャラの足元**を基準に配置したい（頭が基準だと地面に合わない）。
- 制作者として、**武器を持たせる位置**を決めておきたい。
- 制作者として、**アニメーションしても装着位置が破綻しない**でほしい。
- 制作者として、**付けた基準がゲーム側でもそのまま効く**と信じたい。

## 2. 用語

- **原点（origin）**: アセットの基準点（配置の基準）。1 アセットに 1 つ。
- **アンカー（anchor）**: 名前付きの付加点（武器・エフェクト・接地点など）。複数持てる。
- **共通アセット座標**: 保存データの座標（ADR-0001。左上原点・x+ 右・y+ 下・px）。

## 3. 機能要件（FR）

### 3.1 原点

- **FR-1** アセットに**原点を設定**できる。
- **FR-2** よく使う基準（**足元中央・中心・左上**など）を**素早く選べる**（毎回手で合わせない）。
- **FR-3** 原点は**共通アセット座標**で保持する（ADR-0001）。

### 3.2 アンカー

- **FR-4** **名前付きアンカーを複数**追加・編集・削除できる。
- **FR-5** アンカー名は**アセット内で一意**であり、**外部で参照される名前**として扱う（書き出しに出る）。
- **FR-6** アンカーは**用途が分かる形**で扱える（何のための点かを記録できる）。

### 3.3 座標の規律（継承）

- **FR-7** 原点・アンカーは **共通アセット座標**で表す（ADR-0001。`F-2D-03` FR-6 と同一の正本）。
- **FR-8** **grid / snap は配置の補助**であり、**保存座標の意味を変えない**（ADR-0001 / `F-2D-03` FR-7）。
- **FR-9** **出力先（Unity / Godot 等）の pivot 表現の差を、ここで吸収しない**。変換は**書き出し側**（`F-2D-16` / F-CORE-07）が担い、変換式を記録する（ADR-0001）。

### 3.4 フレーム・反転との関係

- **FR-10** **フレームごとに位置が変わりうるか**を扱う（アニメーション中に装着位置が動く場合）。**既定はアセット共通**とし、フレーム単位の扱いは `F-2D-07` と整合させる（詳細は 10 章の未決）。
- **FR-11** **左右反転**したとき、原点・アンカーが**規則どおりに反転**する（系譜: ADR-0005 の反転式の考え方）。反転で意味が壊れない。

### 3.5 操作と確認

- **FR-12** canvas 上で**視覚的に置ける**（`F-2D-03` の選択・ハンドル基盤に乗る）。
- **FR-13** 原点・アンカーの**表示/非表示を切り替え**られる（作業の邪魔をしない）。
- **FR-14** 付与操作は**履歴に乗り**（F-CORE-04）、**非破壊**である（F-CORE-03）。

### 3.6 検証

- **FR-15** **アンカー名の一意性**と、**原点が妥当な範囲にあるか**を検証する（F-CORE-06 の意味検証／出力検証）。
- **FR-16** 書き出し対象に**原点が未設定**の場合、**警告する**（止めるか警告かは preset に従う。F-CORE-06 FR-2 の出力検証）。

## 4. 非機能要件（NFR）

- **NFR-1（正確さ）**: 画面で置いた位置と保存座標が一致する（`F-2D-03` NFR-2 に依存）。
- **NFR-2（非破壊）**: 付与が Source を変更しない（`G5`）。
- **NFR-3（外部での再現性）**: 書き出し後、対象エンジンで**意図した基準として機能**する（`F-2D-16` と対）。
- **NFR-4（明快さ）**: 何が基準で、どこに付いているかが見て分かる。

## 5. データ・保存への影響

- 原点・アンカーは **保存データの一部**（F-CORE-05 の器）。**共通アセット座標**で保持する。
- **表示切替は UI 一時状態**であり保存に混ぜない（F-CORE-01 6 章）。
- 出力先ごとの pivot 変換は**保存側に持たない**（FR-9。書き出し時に変換し、記録する）。

## 6. 依存機能

- **F-2D-03**（Canvas）: 座標の正本・配置操作（FR-7/FR-12）。
- **F-2D-04**（レイヤー & パーツ）: 付与先の単位。
- **F-CORE-03 / 04**: 非破壊・履歴（FR-14）。
- **F-CORE-06**（検品）: 一意性・妥当性の検証（FR-15/FR-16）。
- **F-CORE-07 / F-2D-16**（書き出し）: 外部での意味づけと変換（FR-9/NFR-3）。
- **F-2D-07**（フレーム）: フレーム単位の扱い（FR-10）。

## 7. 受け入れ条件（Acceptance）

- **AC-1**: 原点を設定でき、**よく使う基準を素早く選べる**（FR-1/FR-2）。
- **AC-2**: 名前付きアンカーを複数扱え、**名前が一意**である（FR-4/FR-5/FR-15）。
- **AC-3**: 画面で置いた位置と**保存座標が一致**する（NFR-1）。
- **AC-4**: **snap を使っても保存座標の意味が変わらない**（FR-8）。
- **AC-5**: **左右反転で原点・アンカーが規則どおり反転**し、意味が壊れない（FR-11）。
- **AC-6**: 付与が**履歴に乗り、Source を変更しない**（FR-14/NFR-2）。
- **AC-7**: 原点未設定のまま書き出そうとすると**警告される**（FR-16）。
- **AC-8**: 書き出し時、**出力先の pivot 差が書き出し側で変換**され、変換式が記録される（FR-9、`F-2D-16` と対）。

## 8. 非目標

- 当たり判定（**F-2D-10**）。
- 出力先ごとの pivot 変換の実装（**F-2D-16 / F-CORE-07**）。
- 3D のアンカー（`F-3D-06`）。
- フレーム単位上書きの最終仕様（10 章の未決。`F-2D-07` と併せて決める）。
