## 0. 完成系での位置づけ（逆算リンク）

由来する完成系:

- **D-DONE-2**: ラスタ／ベクタを**非破壊で編集・修正**できる。
- **D-DONE-1**: 空キャンバスから作れる（＝描く手段が要る）。

逆算の理由: **`D-DONE-2` の「編集」の実体**。`F-2D-02`（取り込み）の**修復操作もここに載る**。

そして本コンセプトの対象利用者にはドット絵制作者が含まれる（`APP_COMPETITIVE_LANDSCAPE.md` の Aseprite 参照）。**ドット絵は 1px の意図が結果を決める**ため、**精度と予測可能性**が普通の描画ツール以上に重要になる。

## 1. ユーザーストーリー

- 制作者として、**描く・消す・塗る・選ぶ・動かす**の基本が一通り欲しい。
- ドット絵制作者として、**1px 単位で意図どおり**に置きたい（勝手にぼかされたくない）。
- 制作者として、**1 ストロークが 1 回の Undo** で戻ってほしい。
- 制作者として、**大きな画像でも筆が遅れない**でほしい。
- 制作者として、**取り込んだ元画像が編集で汚れない**と確信したい。

## 2. 機能要件（FR）

### 2.1 基本ツール

- **FR-1** **描画・消去・塗りつぶし・選択・移動・変形**の基本ツールを持つ。
- **FR-2** ツールは**レイヤー種別に応じて働く**（ラスタ層に対して。`F-2D-04` FR-3）。
- **FR-3** **選択範囲**を扱え、範囲内に操作を限定できる。

### 2.2 精度（ドット絵の要求）

- **FR-4** **ピクセル単位の精度**で操作できる。**意図しない補間・ぼかしを既定にしない**。
- **FR-5** 表示倍率に関わらず、**画面で指した位置とデータ上の画素が一致**する（`F-2D-03` FR-8 の変換規範に依る）。
- **FR-6** 変形（拡大縮小・回転）で、**補間方法を選べる**（ドット絵ではニアレスト相当を選べる）。

### 2.3 非破壊と履歴

- **FR-7** 編集は **派生に対して**行い、**取り込んだ Source を書き換えない**（`G5` / F-CORE-03）。
- **FR-8** **1 ストロークを 1 履歴単位**として扱う（F-CORE-04 FR-4 のトランザクション）。連続操作を細切れに履歴へ積まない。
- **FR-9** 操作の**取り消し・やり直し**が Core の履歴経路に乗る（F-CORE-04 FR-1）。

### 2.4 性能

- **FR-10** **大きなキャンバスでも筆の追従が遅れない**（`PF1` の応答性予算）。
- **FR-11** 重い処理（大領域の塗り・変形・フィルタ相当）を **UI から逃がす**（`PF3` / F-PLT-03）。**キャンセルで中途半端な結果を残さない**。

### 2.5 拡張

- **FR-12** **モジュールがツールを追加できる**（`A9` の拡張点）。ただし**同じ非破壊・履歴の規律に従う**（F-CORE-09 FR-11）。

## 3. 非機能要件（NFR）

- **NFR-1（予測可能性）**: 同じ操作が同じ結果になる。勝手に補正しない（FR-4）。
- **NFR-2（非破壊）**: Source が不変（FR-7。`G5`）。
- **NFR-3（応答性）**: 描画の手応えが途切れない（FR-10）。
- **NFR-4（正確さ）**: 指した位置と結果の画素が一致（FR-5）。
- **NFR-5（一貫性）**: モジュール提供ツールも同じ作法（FR-12）。

## 4. データ・保存への影響

- 編集結果は **派生**として保持（F-CORE-03）。**Source は verbatim のまま**（F-2D-02 FR-6 / ADR-0019 の前例）。
- 選択範囲・現在のツール・筆の設定は **UI 一時状態**であり、保存データに混ぜない（F-CORE-01 6 章）。ただし利用者の設定として保存する場合は**編集データと分ける**。

## 5. 依存機能

- **F-2D-03**（Canvas）: 座標・操作面。
- **F-2D-04**（レイヤー）: 編集対象の層。
- **F-CORE-03 / 04**: 非破壊・履歴。
- **F-PLT-03**（offload）: 重い処理（FR-11）。
- **F-2D-02**（取り込み）: 修復操作の載り先。
- **F-2D-13**（パレット / ディザ）: 色の制約をモジュールとして足す先。

## 6. 受け入れ条件（Acceptance）

- **AC-1**: 描画・消去・塗り・選択・移動・変形が使える（FR-1）。
- **AC-2**: **拡大時も 1px 単位で意図どおり**に置ける（FR-4/FR-5/NFR-4）。
- **AC-3**: 変形で**補間方法を選べ**、ドット絵で滲まない（FR-6）。
- **AC-4**: **1 ストロークが 1 回の Undo** で戻る（FR-8、F-CORE-04 AC-2 と対）。
- **AC-5**: 編集後も **Source がバイト不変**（FR-7、F-CORE-03 AC-6 と対）。
- **AC-6**: 大きなキャンバスでも**筆が遅れない**（FR-10）。
- **AC-7**: 重い処理を**キャンセルしても中途半端な結果が残らない**（FR-11、F-PLT-03 AC-3 と対）。
- **AC-8**: モジュール提供ツールが**同じ非破壊・履歴の規律**に従う（FR-12）。

## 7. 非目標

- ツールの網羅（どこまで揃えるかは実装時／モジュールで判断）。
- 高度な画像処理（フィルタ群・合成モードの網羅）。必要ならモジュール。
- ベクタ編集（**F-2D-06**）。
- パレット・ディザの仕組み（`F-2D-13`）。
- ペイントソフトの代替（Vision 7 章の非目標に準じる）。
