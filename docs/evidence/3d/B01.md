## Native contractの具体化

- `.cas3dproj`は初版の**stored ZIP** profile。`manifest.json`、`project.json`、`blobs/<SHA-256>`のみ。既存fflateを使い、圧縮decoderは導入しない。圧縮済みentryは黙って変換せずprofile非対応として拒否する
- native project formatは`chameleon-project-3d`、schemaVersion `0.1.0`。backup manifest formatは`chameleon-backup-3d`、version `0.1.0`。2Dのproject/Asset0.2.0と別の版
- 上限は計画に沿う評価用profile（archive64MiB、JSON8MiB、4096entries）。端末の使用可能memoryや製品対応保証ではない。stored ZIPのため本版ではpayloadも64MiB以内となる。実機profileはB09で確定
- blobはhash照合・byte保持。project JSONにもmanifest hashを持つ。改ざん不能な署名ではなく、転送/保管整合の検査。source権利の利用者申告と埋込条件は別保存
- backupはscene/mesh/material/skin/clip/sourceを再編集可能な形で保存。Undo履歴・UI cameraは初版backup保証外。GLB・sidecarの代用品ではない
- schemaの未知field/未来版は書換え前に拒否。初版以外のmigrationは未実装。未来版を旧版として保存しない
- autosaveは初期案800ms debounce、連続編集時の最大待ち5000ms。設定可能で、background freeze中の期限保証ではない。失敗candidateは保持し、明示retryまたは新しい編集の保存で回復する。2D global queueへ登録しない
- 保存成功はdurable revisionで返し、編集revisionとの比較でdirtyを判断。外部downloadの開始を保存完了にしない
- libraryのbodyを呼べることと、画面・offline cold entry・mobileの受入成立を分ける。本体への接続とbrowser検証は後続で必要
