## Quality report

Inspection captures a detached revision and available bounded blobs. Missing bytes produce partial results and target-specific issues rather than pretending to be measured zeroes. Unique native meshes, instances and actual output are distinguished. Stored-TRS bounds include hidden geometry but are not animated envelopes. Image dimensions come from headers, not proof of successful pixel decode. GPU memory is unknown.

Source inspection verifies hashes, parses bounded metadata without fetching external resources, distinguishes stored rights declarations from detected terms, and lists original-only features. Required extensions may be classified even when unsupported for editable import. VRM metadata detection does not imply VRM editing or export. Rights text is never an application-granted license.

The quality worker shares the asset I/O memory reservation and termination path. Close/background/session replacement cancel it. Edits make results stale; stale links are disabled. Edit links open the relevant section and show the stable target ID while preserving existing unsaved drafts and pose/selection. The user selects the target using existing controls; links never apply an automatic fix.

Export rebuilds important warnings from its own fixed snapshot and retains them in the manifest. A stale screen report cannot leak into a newer output. Current-asset runtime verification remains unverified. Fixture results, validator success and export success cannot upgrade it; a typed evidence matcher requires exact asset/revision/output hashes/runtime/importer versions and all checks.
