# Group 17 Phaser fixture

このfixtureは、Chameleon Asset Studioのdistribution manifestをPhaser 4.2.0で読み込む最小の実ブラウザ確認です。

- CDN: https://cdn.jsdelivr.net/npm/phaser@4.2.0/dist/phaser.min.js
- manifest: packed / scale 2 / 2 pages
- 確認対象: frame rect、trim後のcontentRect、contentOffset、origin、anchor、rect / circle collider、cross-page animation
- `verified`の範囲はこのfixtureと対象versionに限ります。
- 標準atlas完全互換、project自動生成、既存生成sample・helper、物理iPhone Safariは対象外です。
